หน้าเว็บสำหรับเบิก จ่าย ตัดใช้ ตรวจยอดคงเหลือ และ Dashboard ผู้บริหาร

## ขอบเขต

ระบบนี้มีเฉพาะคลังย่อย คลังใหญ่อยู่ในระบบอื่น ไม่เชื่อมต่อกัน
ใบเบิกเป็นเอกสารขอไปยังคลังใหญ่ เมื่อได้ของให้ทำรายการ "รับเข้า" อ้างอิงใบเบิก พร้อมใส่ Lot วันหมดอายุ และราคาต่อหน่วยทุกครั้ง
ใบรับเข้าเลือกบริษัทผู้ขายจากทะเบียน และใส่เลขที่/วันที่เอกสารอ้างอิง (ใบรับของ/ใบส่งของ) ได้ ข้อมูลนี้แสดงใน Stock Card และรายงานความเคลื่อนไหว

## หน้าจอหลัก

| หน้าจอ | ใช้ทำอะไร |
| --- | --- |
| Setup & Access | เพิ่มคลังย่อย ผู้ใช้และบทบาท ตั้งสิทธิ์เข้าถึงรายหน้าจอ |
| ใบเบิก | สร้างใบเบิกถึงคลังใหญ่ (ดูยอดคงเหลือและ Min/Max), ประวัติการเบิก |
| รับเข้า | รับตามใบเบิกพร้อม Lot วันหมดอายุ ราคา บริษัท เลขที่เอกสาร, รับของโอนจากคลังย่อยอื่น, ประวัติการรับ |
| ตัดจ่ายและโอนย้าย | จ่ายผู้ป่วย/ตัดใช้, โอนไปคลังย่อยอื่น, ตัดชำรุด/หมดอายุ |
| Stock Card และรายงาน | บัญชีคุมคลังพร้อมยอดสะสม, ยอดคงเหลือราย Lot และทุนเฉลี่ย, ความเคลื่อนไหว, ประวัติการเบิก |
| แจ้งเตือน | ใกล้หมดอายุ, ต่ำกว่า Min, ของโอนรอยืนยันรับ |
| สินค้าประจำคลัง | ผูกสินค้ากับคลัง ตั้ง Min/Max ดูทุนเฉลี่ยและมูลค่า, ทะเบียนบริษัทผู้ขาย |

## ราคาทุน

ใช้ราคาทุนเฉลี่ยเคลื่อนที่ (Moving Average) แยกรายคลังและรายสินค้า
ทุกครั้งที่รับเข้า: ทุนเฉลี่ยใหม่ = (คงเหลือเดิม × ทุนเฉลี่ยเดิม + จำนวนรับ × ราคารับ) ÷ (คงเหลือเดิม + จำนวนรับ)
การจ่าย ตัดชำรุด และโอนออกใช้ทุนเฉลี่ย ณ ขณะนั้น คลังปลายทางที่รับโอนนำราคานั้นไปเฉลี่ยกับของเดิม

## บทบาทผู้ใช้

| role | ชื่อในระบบ | ทำอะไรได้ |
| --- | --- | --- |
| `requester` | Sub-stock User | เบิก รับเข้า ตัดจ่าย ขอโอน/ตัดชำรุด เฉพาะคลังตนเอง |
| `unit_head` | Sub-stock Admin | เหมือน Sub-stock User + อนุมัติเอกสารของคลังตนเอง + ผูกสินค้าและตั้ง Min/Max คลังตนเอง |
| `manager` | ผู้บริหาร | Dashboard อนุมัติใบปรับยอด ดูทุกคลัง |
| `admin` | ผู้ดูแลระบบ | ทุกอย่าง + Setup & Access + ทะเบียนสินค้ากลาง |

### สิทธิ์รายผู้ใช้ (ตั้งที่ Setup & Access → ผู้ใช้)

| สิทธิ์ | ใช้กับ |
| --- | --- |
| ขอเบิก | คลังที่สังกัด + คลังอื่นที่เลือกใน "ขอเบิกแทนคลังอื่น" (ขอเบิกได้หลายคลัง) |
| รับเข้า | คลังที่สังกัด (รวมยืนยันรับของโอน) |
| จ่ายออก | คลังที่สังกัด |
| โอน | คลังที่สังกัด |
| ตัดชำรุด/หมดอายุ | คลังที่สังกัด |

ผู้ดูแลระบบมีสิทธิ์ทุกอย่าง · การอนุมัติใช้ตามบทบาท

สิทธิ์ข้อมูล (เห็น/แก้ได้เฉพาะคลังตนเอง) บังคับในฐานข้อมูลด้วย Row Level Security
ตารางสิทธิ์หน้าจอในหน้า Setup ใช้ซ่อน/แสดงเมนูเท่านั้น

## สถานะเอกสาร

- ใบเบิก: รออนุมัติ → อนุมัติแล้ว → เสร็จ (เมื่อทำรายการรับเข้าอ้างอิงใบเบิกนี้)
- โอน: รออนุมัติ → ระหว่างส่ง (ตัดยอดต้นทางแล้ว) → เสร็จ (ปลายทางยืนยันรับ)

## หมายเหตุความปลอดภัย

คีย์ Supabase ใน `index.html` เป็นคีย์สาธารณะ (publishable key) ที่ออกแบบให้อยู่ในหน้าเว็บได้
ข้อมูลถูกป้องกันด้วยการล็อกอินและ Row Level Security ในฐานข้อมูล
ห้ามนำคีย์ `service_role` หรือ secret key มาใส่ในไฟล์นี้
