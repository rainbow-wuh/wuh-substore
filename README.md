# ระบบคลังย่อย (Sub-Store) โรงพยาบาลศูนย์การแพทย์ มหาวิทยาลัยวลัยลักษณ์

หน้าเว็บสำหรับเบิก จ่าย ตัดใช้ ตรวจยอดคงเหลือ และ Dashboard ผู้บริหาร
ฐานข้อมูลอยู่ที่ Supabase โปรเจกต์ `wuh-substore`

- เว็บ: https://rainbow-wuh.github.io/wuh-substore/
- ฐานข้อมูล: https://supabase.com/dashboard/project/oxcrpbmcmzfomsclmdng

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บทั้งหมด (HTML + JavaScript ไฟล์เดียว) |
| `.nojekyll` | บอก GitHub Pages ให้ส่งไฟล์ตามเดิม ไม่ต้องแปลง |

## หน้าจอหลัก

| หน้าจอ | ใช้ทำอะไร |
| --- | --- |
| Setup & Access | กำหนดหน่วยงานเป็นคลังใหญ่/คลังย่อย, เพิ่มผู้ใช้และบทบาท, ตั้งสิทธิ์เข้าถึงรายหน้าจอ |
| ขอเบิกและรับเข้า | สร้างใบเบิกพร้อมยอดคงเหลือและ Min/Max, ตรวจ Lot/วันหมดอายุแล้วยืนยันรับเข้า, ประวัติการเบิก |
| ตัดจ่ายและโอนย้าย | จ่ายผู้ป่วย/ตัดใช้, โอนระหว่างคลังย่อย, คืนคลังใหญ่, ตัดชำรุด/หมดอายุ |
| Stock Card และรายงาน | บัญชีคุมคลังพร้อมยอดสะสม, ยอดคงเหลือราย Lot, ความเคลื่อนไหวรับ-จ่าย, ประวัติการเบิก |
| แจ้งเตือน | ใกล้หมดอายุ, ต่ำกว่า Min, ของรอยืนยันรับ |

## บทบาทผู้ใช้

| role | ชื่อในระบบ | ทำอะไรได้ |
| --- | --- | --- |
| `requester` | Sub-stock User | เบิก รับเข้า ตัดจ่าย ขอโอน/คืน/ตัดชำรุด เฉพาะคลังตนเอง |
| `unit_head` | Sub-stock Admin | เหมือน Sub-stock User + อนุมัติเอกสารของคลังตนเอง + ตั้ง Min/Max คลังตนเอง |
| `main_store` | คลังใหญ่ | รับจากผู้ขาย จ่ายตามใบเบิก รับคืน จัดการสินค้า ดูทุกคลัง |
| `manager` | ผู้บริหาร | Dashboard อนุมัติใบปรับยอด ดูทุกคลัง |
| `admin` | ผู้ดูแลระบบ | ทุกอย่าง + Setup & Access |

สิทธิ์ข้อมูล (เห็น/แก้ได้เฉพาะคลังตนเอง) บังคับในฐานข้อมูลด้วย Row Level Security
ตารางสิทธิ์หน้าจอในหน้า Setup ใช้ซ่อน/แสดงเมนูเท่านั้น

## สถานะเอกสาร

ร่าง → รออนุมัติ → อนุมัติแล้ว → ระหว่างส่ง (ตัดยอดต้นทางแล้ว) → เสร็จ (ปลายทางยืนยันรับ)

## หมายเหตุความปลอดภัย

คีย์ Supabase ใน `index.html` เป็นคีย์สาธารณะ (publishable key) ที่ออกแบบให้อยู่ในหน้าเว็บได้
ข้อมูลถูกป้องกันด้วยการล็อกอินและ Row Level Security ในฐานข้อมูล
ห้ามนำคีย์ `service_role` หรือ secret key มาใส่ในไฟล์นี้
